# CLAUDE.md

The working agreement for this repository is [`AGENTS.md`](AGENTS.md), for every agent and every person. It is imported here so that Claude Code reads it as its own:

@AGENTS.md

Do not duplicate rules into this file. Change `AGENTS.md` instead.

What is in `.claude/` is Claude Code's own and holds no rule of its own: `.claude/rules/workspaces.md` is given to it when it opens a file of a workspace, and points at that workspace's Rules in its `README.md`; `.claude/settings.json` keeps the secret files from it and allows the checks.
